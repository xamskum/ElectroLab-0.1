# ElectroLab

**3D браузерная образовательная игра**, в которой игрок изучает электричество и основы электроники через эксперименты, а не через лекции.

> **Важно:** это сырой прототип (vertical slice). Сейчас полностью проработан только Level 1.  
> Код открыт — можно дорабатывать, добавлять уровни, улучшать симуляцию, UI, графику и геймплей.

---

## Идея

Игрок находится в 3D-лаборатории от первого лица.  
В комнате есть батарея, провода, дверь (и другие компоненты на следующих уровнях).

Чтобы пройти уровень, нужно **самому собрать работающую электрическую цепь**.

Никаких готовых «нажми кнопку — дверь откроется».  
Дверь открывается только тогда, когда `CircuitSolver` видит реальный замкнутый путь и достаточный ток.

После успешного эксперимента появляется короткое объяснение физического принципа.

**Философия:** *Learn by doing* — сначала эксперимент и ошибка, потом теория.

---

## Что уже работает

- 3D-комната лаборатории (low-poly)
- FPS-управление (WASD + мышь)
- Реальная система цепей (hybrid Modified Nodal Analysis)
- Компоненты: Battery, Wire, Door, Switch, Lamp, Resistor
- Подключение/отключение проводов
- Визуализация тока (частицы по проводам)
- Дверь реагирует на реальное состояние схемы
- Подсказки (3 уровня)
- Knowledge Panel после прохождения
- localStorage (заготовка)

**Level 1 — «Первый контакт»**  
Цель: открыть дверь, создав замкнутую цепь.

## Технологии

- TypeScript
- Three.js
- Vite
- WebGL
- Чистый фронтенд (без backend)

Структура:

```
src/
  core/          — движок и игровой цикл
  player/        — FPS-контроллер и взаимодействие
  electricity/   — Terminal, CircuitSolver, ElectricalComponent
  components/    — Battery, Wire, Door, Switch, Lamp…
  levels/        — комнаты и логика уровней
  ui / audio / save
```

## Как запустить

### Самый простой способ (standalone)

```bash
cd standalone
python3 -m http.server 8080
```

Открыть: [http://localhost:8080](http://localhost:8080)

### Разработка (Vite)

```bash
npm install
npm run dev
```

## Для тех, кто хочет доработать

Проект специально сделан расширяемым:

- Новый компонент = наследник `ElectricalComponent` + регистрация в solver
- Новый уровень = отдельный класс в `levels/`
- Симуляция уже отделена от 3D-моделей (модели только отображают состояние)

Что особенно нужно:

- Level 2–5
- Более удобный UI проводов
- Progress map и сохранение прогресса
- Звуки лаборатории
- Мобильное управление
- Песочница (sandbox mode)
- Более красивые модели / освещение

Pull requests и форки приветствуются.
