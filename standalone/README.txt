ElectroLab — standalone playable build

Запуск:
  python3 -m http.server 8080
  http://localhost:8080
  Ctrl+Shift+R

Управление:
  WASD — ходьба
  Мышь — взгляд (клик по canvas)
  E — взаимодействие / соединить провод
  ESC — отмена провода
  C — отладка цепи (I, R, P)

Уровни 1–5: цепь, выключатель, лампа, последовательно, параллельно.
